rokh-forms

An offline sheet. Nothing here reaches a network, and typing records nothing.
Drafts are not events. What you type is kept in this browser only. It becomes ledger history when you run the commit command — never before, and never on its own.

Commit

Export a bundle, then hand it to the CLI. A page opened with file:// cannot reach a Unix socket, so the handoff is a file — no listener is added to Rokh. 

rokh-forms commit --carrier DIR --content-root DIR --bundle rokh-commit.json
rokh-forms render --carrier DIR --content-root DIR --out forms.html
Committed state below each form is a projection rendered from the ledger. This file is mutable and disposable; the ledger is not. Deleting this page loses nothing.
