# Contributing to rokh-lab

- **To ask the owner for a ruling,** open an issue with the question form, or
  a pull request with a new record made from
  [the template](templates/question.md). Say what is asked, why, with the
  evidence, what changes once it is ruled, and what it blocks. A question
  opened with the form takes its number when its record is written in
  `questions/`; its issue then takes the record's title, `D-nn: …`, and
  follows the record from then on.
- **To bring a study,** open an issue with the study form first, so that it is
  not done twice; then a pull request with its folder, `studies/NNNN-words/`,
  made from [the template](templates/study.md), with its data.
- **To examine a question,** add evidence on its issue, or bring a study.
- **To correct a study,** a pull request that says what it corrects and why;
  the study's history keeps what it said before.
- **A weakness in security** is never written here before it is repaired:
  report it privately, as the
  [security policy](https://github.com/Karvareh/.github/blob/main/SECURITY.md)
  says.

Read [AGENTS.md](AGENTS.md) first. A pull request here has one concern, its
commits are in English, in the present tense, the check of `tools/records`
passes, and the owner merges it.
