# Contributing to rokh-work

- **To take up a mission,** claim it on its issue, and follow
  [How to pick one up](README.md#how-to-pick-one-up). The work itself lands in
  the repository the mission names, as a pull request there.
- **To propose a mission,** open an issue with the mission form, or a pull
  request with a new record made from [the template](templates/mission.md).
  Say why, with the evidence; the change; where; what it needs; and the test
  that says it is done. A mission opened with the form takes its number when
  its record is written in `missions/`; its issue then takes the record's
  title, `W-nn: …`, and follows the record from then on.
- **To mark a mission done,** after the owner merged its work: a pull request
  here that sets `status: done` and names the commit.
- **A weakness in security** is never a mission and never an issue: report it
  privately, as the
  [security policy](https://github.com/Karvareh/.github/blob/main/SECURITY.md)
  says.

Read [AGENTS.md](AGENTS.md) first. A pull request here has one concern, its
commits are in English, in the present tense, the check of `tools/records`
passes, and the owner merges it.
